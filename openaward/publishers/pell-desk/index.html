How other sites use this desk

  1. A passport site asks the student, then opens this desk's action bridge in a hidden frame on this origin.
  2. It reads the published rules with get_published_rules. Nothing about the student is sent.
  3. After the student picks the fields to share, it calls check_eligibility with only those fields. This desk's code screens them and returns each rule's status with its source. It stores nothing.
